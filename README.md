# Séances Indé

Prototype de site autour de la programmation des cinémas indépendants à partir du dataset SCARE / datacinesindes.

## Fichiers
- `index.html`
- `style.css`
- `app.js`

## Déploiement
Déploiement prévu sur Render en site statique depuis GitHub.

## Source de données
- Dataset `programmation-cinemas`
- Endpoint `data-fair/api/v1/datasets/programmation-cinemas/lines`
